সাফওয়ান এন্টারপ্রাইজ — Android অ্যাপ প্রজেক্ট

এই ZIP-এ Android Studio প্রজেক্টের সোর্স কোড আছে; এটি APK ফাইল নয়।

APK বানানোর নিয়ম:
1. কম্পিউটারে Android Studio ইনস্টল করুন।
2. Android Studio থেকে এই ZIP Extract করে SafwanEnterprise ফোল্ডারটি Open করুন।
3. Gradle Sync শেষ হতে দিন।
4. Build > Build Bundle(s) / APK(s) > Build APK(s) নির্বাচন করুন।
5. তৈরি APK পাবেন: app/build/outputs/apk/debug/app-debug.apk

অ্যাপের নাম: সাফওয়ান এন্টারপ্রাইজ
Package: com.safwan.enterprise
অর্ডার ডেটা এই ডিভাইসের WebView storage-এ থাকবে। নিয়মিত অ্যাপের ব্যাকআপ অপশন ব্যবহার করুন।
